# Study Resource Recommendation System

Flask website that recommends study resources using the original Python logic:
Pandas dataset, one-hot encoding, and cosine similarity.

## Run locally

On this Windows PC, use the Python launcher (`py`) because the `python` command is not on PATH:

```bash
cd C:\Users\user\Projects\study-resource-recommendation-system
py -3.14 -m pip install -r requirements.txt
py -3.14 app.py
```

Then open http://127.0.0.1:5000 in your browser.
